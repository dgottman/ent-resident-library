# Image and figure attribution

Future images belong beneath `public/images`. Keep a clear folder per guide or
topic, and use the reusable `components/figure.tsx` component so every figure can
carry:

- descriptive alt text;
- a caption;
- source or attribution;
- an optional figure number;
- an optional link to the original source.

Only publish images that are:

- original;
- properly licensed for the intended use;
- public domain;
- or used with explicit permission.

Citation is not permission. Do not copy clinical atlas images, journal figures,
commercial diagrams, or patient photographs merely because their source is
named.

For each new asset, keep a local record of creator, source URL, license,
permission, modifications, and date accessed. Alt text should explain the visual
information needed to understand the figure rather than repeat the caption.

Never include patient-identifying features unless the owner has confirmed a
lawful, documented publication basis and the use is appropriate.
